# examples — หน้าตัวอย่าง (ไม่ได้ลงทะเบียนในระบบ)

โฟลเดอร์นี้คือ "ต้นแบบ" ที่ไว้ลอก ไม่ใช่ส่วนหนึ่งของระบบที่รัน — ไม่อยู่ใน `src/pages/index.ts` จึงไม่มีตาราง/เมนู/API ของมันในโปรเจกต์ใหม่
ยังถูกตรวจ TypeScript และทดสอบทุกครั้ง (`npm run check`, `npm test`) เพื่อให้ต้นแบบไม่เสีย

| ตัวอย่าง | ใช้เป็นต้นแบบของ |
|---|---|
| `vendor/` | หน้า CRUD: ตาราง + กรอง + เพิ่ม/แก้/ลบ + modal เลือกจากตาราง |

สร้างหน้าใหม่จากต้นแบบ: `npm run new:page <ชื่อ> -- --label <ชื่อไทย>` (ดู docs/03)
**อย่าก๊อปโฟลเดอร์นี้ทั้งโฟลเดอร์ไปไว้ในโปรเจกต์ใหม่** — เลือกต้นแบบที่ใกล้เคียงแค่หน้าเดียว
